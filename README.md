A deterministic program that writes one single-line joke about office life — the kind of line you send a colleague after a meeting that should have been an email — to `entry.txt`. The joke: HR answers a question about work-life balance by booking a 30-minute meeting titled "Balance".

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-24nov-out python3 main.py
```
